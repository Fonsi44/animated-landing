# Animated Landing

Scroll-orchestrated landing page showcasing GSAP ScrollTrigger, useGSAP, and compositor-friendly animations.

- **Live:** [animated-landing.vercel.app](https://animated-landing.vercel.app)
- **Portfolio:** [portfolio-hub-flax.vercel.app](https://portfolio-hub-flax.vercel.app)

## Features

- Hero timeline with staggered entrance
- ScrollTrigger reveals on feature cards
- Ambient glow pulse animation
- Respects `prefers-reduced-motion`
- Matching design system with portfolio hub (cyan/dark)

## Stack

- Next.js 16 · GSAP · @gsap/react · ScrollTrigger · Tailwind v4

## Local

```bash
npm install
npm run dev
```
